# ime.ahk-v2

> **保守終了のお知らせ**
> 本リポジトリの保守は終了しました。コードと変更履歴は参照用に残します。
> 別の v2 移植版については、下記の「原作者・関連する v2 移植版」を参照してください。

AutoHotkey v2 で日本語 IME の ON/OFF を取得・設定するためのライブラリです。本リポジトリでは、次の2関数を提供しています。

- `IME_GET(WinTitle := "A")`：IME の ON/OFF 状態を取得
- `IME_SET(SetSts, WinTitle := "A")`：IME の ON/OFF 状態を設定

## 原作者・関連する v2 移植版

元となる AutoHotkey v1 用ライブラリ `IME.ahk` は、[eamat さん](https://w.atwiki.jp/eamat/pages/17.html)が作成されたものです。本リポジトリは、そのうち ON/OFF を扱う2関数を AutoHotkey v2 に対応させた派生版です。

入力モード・変換モードの取得や設定、変換中の判定など、より多くの機能が必要な場合は、綾木健一郎（k-ayaki）さんによる別の v2 移植版 [IMEv2.ahk](https://github.com/k-ayaki/IMEv2.ahk) も参照してください。

対象が非アクティブの場合の動作など、本リポジトリとは仕様が異なるため、移行する際は利用しているスクリプトで動作を確認してください。

```ahk
    stGTI := Buffer(cbSize, 0)
```

の箇所だったと記憶しています。

もともとv1にはBufferというカプセル化するためのオブジェクトがなかったようです。
